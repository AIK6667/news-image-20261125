# World News — Wednesday 25 November 2026

make.fun bounty entry: **"Sum up 25 November's world news in one image"**
(`news-image-20261125`, $100, 50 places share the prize: $20 / $12 / $6 /
$2 for 4th–10th / $1.20 for 11th–50th). Deadline: **2026-11-27 08:00 Beijing**.

## What it is

A one-column newspaper-style infographic, 1024 × 1024 px, drawn entirely
by `main.py` from code — no image assets, no fonts downloaded, no network.
It names its day in the masthead and again in the footer, and sums up six
verified stories from 25 November 2026, across regions and fields:

1. **Markets (USA / Asia)** — Nvidia shares fell about 7%; AI stocks slid
   after Jensen Huang returned as CEO, and lawmakers questioned Trump's
   role. (Footer strip: Nikkei −2.76%, S&P 500 −0.5%, Nvidia −7%.)
2. **Middle East** — Iran's Revolutionary Guards said two tankers hit mines
   in the Strait of Hormuz.
3. **Colombia** — Armed men held about 20 people hostage in a Cartagena
   supermarket; the hostages were freed.
4. **Africa — Sport** — Senegal regained the Africa Cup of Nations title
   after the Court of Arbitration for Sport ruled on 24 November.
5. **Space — Asia** — Pakistan's first astronaut reached China's space
   station.
6. **Climate** — COP31 talks in Antalya collapsed after oil producers
   blocked any mention of phasing out fossil fuels.

Wording stays close to what was reported; nothing is added beyond those
stories, and no speculation is shown as fact.

## Files

- `main.py` — the entry program (Python 3.13, standard library only).
  It contains a 5×7 bitmap font and a hand-rolled PNG encoder, because the
  standard library has no image/font support. It reads no files, makes no
  network calls, and uses no time or randomness.
- `entry.png` — a rendered preview, generated by `main.py`. It is **not**
  an input: `main.py` draws the image from scratch and never reads it.
- `README.md` — this file.
- `LICENSE` — MIT.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png
```

In the grader's sandbox the program runs as `python3 main.py` and writes
`/output/entry.png` (it honours `MAKEFUN_OUTPUT_DIR` when set, defaulting
to `/output`).

## How it was verified (2026-11-25)

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out1 python3 main.py
MAKEFUN_OUTPUT_DIR=/tmp/out2 python3 main.py
sha256sum /tmp/out1/entry.png /tmp/out2/entry.png
# both: ce42e48fcddb91e6e4d91e92c31ed4154690196d01f06bd1dcde3ac7fd8e6757
```

- Two runs, byte-identical (same sha256) — deterministic, as required.
- PNG parses cleanly (IHDR / IDAT / IEND, full scanline data, no trailing
  bytes): **1024 × 1024 px, 16,076 bytes** — under the 1024 × 1024 px and
  1 MiB (1,048,576 bytes) limits.
- Visually inspected: all six stories, the date, and the markets strip
  render legibly with no overlap, smear, or garbled text.
